# Roadmap

**Current owner priorities (September 9):** use [NEXT-STEPS.md](../NEXT-STEPS.md) for the concrete acceptance checklist. It supersedes older sequencing: complete a hosted real audit, activate Google measurement/search, validate the client readout and recurring review, decide advisor access, then prove incremental department scope. The broader direction below remains context.

This is a prioritized direction, not a delivery-date commitment. The pilot must prove useful discovery before expansion into autonomous operations.

## Now: make the pilot repeatable

| Work | Acceptance evidence |
| --- | --- |
| End-to-end real discovery rehearsal | Authorized invitation, private entry, recording/transcript, granular cards, approval, advisor return all verified |
| Extraction quality | Representative accounts scored for omitted/invented tasks, handoffs and correction effort |
| Advisor findings | Reviewer can trace each gap/candidate to task/evidence and explain the next action |
| Clean client readout | Understandable map, decisions, owners and follow-up; no fabricated metrics |
| Reliable intake and delivery | Saved application plus actual notification receipt; delivery failure visible |
| New developer onboarding | Fresh clone/setup and a scoped contribution without private handoff knowledge |

## Next: advisor scale and operating trust

Train advisors to run a consistent kickoff, ask good questions, review uncertainty, and present actionable findings. Use pilot feedback to establish a delivery playbook and internal-owner handoff.

Add production recovery evidence, monitoring, identity/account administration, retention/deletion controls, and larger-workspace performance acceptance. Define customer success and incident ownership.

Measure participant completion, time to reviewed cards, advisor hours, correction rate, resolved ownership gaps, and agreed follow-up actions. Do not substitute page views or generated-card counts for customer value.

## Then: enterprise governance

Build real connector adapters only after data shapes and authority semantics are validated. Prove identity matching, effective entitlement freshness, policy conflict checks, reviewer authority, signed manifests, revocation, and runtime enforcement.

Validate a managed-service isolation/cost model and channel licensing requirements. A strategic introduction is an opportunity to learn; it is not product-market fit or a signed partnership.

## Later: adaptive strategy

Connect changing evidence to fresh framework interpretation and proposed changes. Keep proposed actions distinct from authorized work. Add outcome feedback and explainable recommendations before considering automatic execution.

A company-profile-to-operational-flow compiler, automated cross-team reconciliation, and continuous strategist should be developed with reviewable evidence and explicit authority, not by creating plausible graph edges.

## Open decisions

- Who owns long-term record quality after handoff?
- Which connector/runtime is the first real enforcement target?
- What enterprise deployment/isolation options are commercially necessary?
- What measured cost and support burden support subscription pricing?
