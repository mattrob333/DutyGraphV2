Microsoft Agent 365

Admin control plane for AI agents in Microsoft 365. Its registry lists Microsoft, partner-built, org-published and user-shared agents available to a tenant, and a preview Shadow AI view detects unapproved local agents on managed devices using Defender for Endpoint, with extra usage metadata from Global Secure Access. Registry coverage is Microsoft-ecosystem centric.

commercial · generally available · Research snapshot 2026-09-06

Capabilities and evidence

Support labels reflect the supplied research. Documentation and vendor claims are not independent product tests. “Not established” means the researcher did not find support; it does not prove a capability is absent.

Documented by provider

The agent registry in the Microsoft 365 admin center gives a centralized view of all agents available to an organization, split into Microsoft agents, external partner-built agents, agents published by the org, and agents shared by their creator.

Limit: Registry lists agents available in the Microsoft ecosystem; agents on other platforms are not covered by this view.

Source s1

Documented by provider

A preview Shadow AI page detects and governs unmanaged AI agents such as OpenClaw, requiring Microsoft Defender for Endpoint for shadow agent detection, Microsoft 365 E5, Intune enrolment, and Global Secure Access for additional usage metadata.

Limit: Explicitly public preview under the Frontier programme; supported agents and behaviours may change, and detection requires the listed Microsoft stack.

Source s2

Documented by provider

Microsoft announced general availability of Agent 365 for commercial customers on 1 May 2026 as a control plane to observe, govern and secure agents, including agents from ecosystem partners.

Limit: Several capabilities announced alongside GA are described as previews; partner coverage depth is not specified.

Source s3
