Tonic Textual

Tonic.ai's de-identification product for unstructured text. It scans files and strings with named-entity models, then redacts or replaces sensitive values with consistent synthetic substitutes for use in LLM prompts, RAG corpora and training sets, with guided review. Governance features beyond RBAC and SSO are not documented.

commercial · generally available · Research snapshot 2026-09-06

Documented by provider

Textual scans dataset files to identify sensitive values and lets users redact or replace them, including guided redaction projects with human review before output files are downloaded.

Limit: Documentation does not state detection accuracy or language coverage.
