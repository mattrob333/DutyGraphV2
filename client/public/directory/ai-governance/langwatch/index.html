LangWatch

Dutch open-source LLMOps platform that automatically tracks every LLM call, tool usage and user interaction as traces, spans and metadata, adds prompt versioning, dataset experiments and multi-turn agent testing against a simulated user. Self-hosted and enterprise editions document audit logs, RBAC and SSO/SCIM.

Capabilities and evidence

Support labels reflect the supplied research. Documentation and vendor claims are not independent product tests. “Not established” means the researcher did not find support; it does not prove a capability is absent.

Documented by provider

LangWatch automatically tracks every LLM call, tool usage and user interaction with detailed traces, spans and metadata, showing the full conversation flow, and supports agent testing of multi-turn conversations with a simulated user.

Limit: Multi-agent handoffs and human feedback capture are not documented on the introduction page.

Source s1

Documented by provider

Self-hosting documentation states the same software as LangWatch Cloud can be self-hosted for data sovereignty, regulatory compliance or air-gapped environments with no separate community or enterprise build, and lists audit logs giving visibility into who did what and when, role-based access control with fine-grained permissions across projects and teams, and SSO with SCIM provisioning.

Limit: Retention configuration and PII redaction are not documented on that page, and audit-log contents and immutability are not specified.

Source s2

Documented by provider

Documented deployment models include self-hosted, Cloud Enterprise with dedicated instances in a chosen cloud region, and a hybrid model where LangWatch runs the control plane while ClickHouse and S3 data planes sit in the customer VPC.

Limit: Compliance references (GDPR, SOC 2) appear as motivations for self-hosting rather than as certifications of the vendor.

Source s2

Documented by provider

The introduction describes an AI Gateway with budgets, routing policies and anomaly detection, and evaluations positioned to guard against harm.

Limit: No documented enforcement semantics, policy language or blocked-call logging.

Source s1

Limitations to discuss

  • Audit logs and RBAC are documented as features of the self-hosted/enterprise editions without detail on log contents, immutability or retention.
  • Simulation and evaluation features overlap with dedicated eval vendors; depth per feature is thinner than in single-purpose tools.
