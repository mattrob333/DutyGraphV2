Agent building & orchestration

CrewAI

Open-source Python framework for orchestrating role-based agent crews, paired with CrewAI AMP, a hosted platform that deploys crews, exposes them via REST, streams events and shows execution traces. Human review is a framework-level pattern; platform documentation reviewed showed no approval console or audit-log feature.

hybrid · generally available · Research snapshot 2026-09-06

Support labels reflect the supplied research. Documentation and vendor claims are not independent product tests. “Not established” means the researcher did not find support; it does not prove a capability is absent.

Documented by provider

The open-source framework orchestrates role-playing autonomous agents with production-ready patterns including deterministic steps, human input, structured outputs and checkpointing.

Limit: Repository documentation does not define enterprise policy controls around those patterns.

Source s2

Documented by provider

CrewAI AMP deploys crews to managed infrastructure via GitHub integration, Crew Studio or CLI, exposes them through generated REST endpoints, streams real-time events and provides detailed execution traces and logs.

Limit: The introduction page documents no audit-log, RBAC, versioning or tenant-isolation features.

Source s1

Documented by provider

Human-in-the-loop workflows are supported, with human review configurable on tasks.

Limit: Implemented in code per task; no reviewer role model or approval audit trail is documented.

Source s2

Vendor claim

Limit: The self-hosted docs site was referenced in search results but its configuration details were not fetched in this session.

Limitations to discuss

  • Governance is developer-only in the sources reviewed: no approval console, RBAC, versioning or tenant-isolation documentation.
  • Self-hosted platform configuration was not verified.
  • Product naming shifted from CrewAI Enterprise to CrewAI AMP.
