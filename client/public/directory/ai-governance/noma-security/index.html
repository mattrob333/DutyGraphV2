Noma states it discovers every agent, MCP server, skill and model across endpoint, SaaS and homegrown environments and correlates each agent's connections, permissions and data access to surface toxic combinations.

Vendor claim

Runtime protection is described as evaluating each action in context and, based on policy, alerting, blocking, masking data or routing to a human, catching prompt injection, data exfiltration and scope violations.

Limit: Human-approval routing is asserted on a solution page without workflow documentation.
